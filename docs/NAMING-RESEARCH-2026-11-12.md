Luffy's specific focus is explicit comment-triggered reviews, bounded context, repository memory and redacted traces. A standalone name should be paired with that plain description rather than imply benchmark leadership or general autonomous engineering.

## Collision checks and decision

Exact-name web searches and GitHub repository searches found existing review-related uses of PatchWitness, DiffHarbor, DiffLoom and Diffwarden. PatchRecall is an existing program-repair research name; ReviewTrail is used for customer-review management. Those were rejected. ReviewKeel had no matching result in the web and GitHub checks performed; absence from search does not establish legal availability.

ReviewKeel was proposed with the rationale that a keel suggests steady, repeatable review. The owner explicitly chose **Keep Luffy for now** on 12 November 2026. Therefore the product, repository, workflows, runtime variables, paths and historical artifacts retain Luffy. No migration or compatibility change is required. Public profiles should use **Luffy — PR review with repository memory and redacted audit traces**.
